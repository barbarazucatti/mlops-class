# Aula 4 - Pipeline de MLOps Para Operacionalização e Monitoramento de IA Generativa com LLM e RAG
# Instruções Para Execução do Projeto

# Nota: O LLM (BERT) é executado localmente no container da app, via biblioteca transformers (PyTorch CPU).


# 1- Inicialize o Docker Desktop.

# 2- Abra o terminal ou prompt de comando, navegue até a pasta raiz com os arquivos e execute o comando abaixo para criar os containers:

docker-compose up --build -d

# Nota: Será preciso editar 2 arquivos e colocar o nome do hostname do container do ElasticSearch, conforme mostrado nas aulas.

# 3- Abra o navegador e acesse o Airflow para ativar a DAG:

localhost:8080

username: airflow
password: airflow

# 4- Abra o navegador e acesse a app web para interagir com o LLM (espere alguns segundos até o ElasticSearch finalizar a indexação):

localhost:8501

# Nota: A primeira pergunta demora mais, pois o modelo (~1,3 GB) é baixado e carregado na memória. As seguintes são rápidas.

# Exemplos de perguntas:

# Can you provide more details on the clarification provided in Note 1?
